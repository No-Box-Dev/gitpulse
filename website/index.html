What you get

Live PR feed

Every PR your team opens, merges, and releases becomes a first-person post — narrated by AI so scanning is fast and reads like a Slack channel, not a diff-viewer.

Current — who's shipping

A per-person view of open PRs, review requests, and assigned issues. Counts on every row so you can see who's blocked, who's shipping, and who has stuff waiting on you.

Full app when you need it

Global ⌘⇧X opens the menubar popover from anywhere. When you want the bigger view, open the full window — same feed, more room.

Multi-account, multi-org

Sign in with more than one GitHub identity. Switch between orgs instantly. Every account has its own Keychain slot and its own preferences remembered.

Admin controls inline

Admins can manage tracked repos, team visibility, and trigger sync directly from the app. No need to bounce to the browser to hide someone from the feed or park a repo.

PR detail with source toggle

Click any PR anywhere in the app to open the detail view. Toggle between release notes generated by NoxFeed and the GitHub page (embedded, signed in).

Ready to try it?

Free on the Mac App Store. Works with any GitHub org connected through NoxConnect.
